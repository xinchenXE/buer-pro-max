# 权威与可写范围

> 回答一个问题：**我现在能不能动这个文件？**
> 答不出来的时候，**按更严的一档处理，并登记一条偏差**——不要「先改了再说」。

---

## 一、权威来源分类（先分类，再定档） 【必选】（两层形态）/ 乙类部分可选 · 触发：有外部上游

**按来源分，不按目录名分。** 同一个目录里可能同时住着三类内容。

| 类 | 特征 | 命运 | 可写性 |
|---|---|---|---|
| **甲 · 本体** | 自己写的；外部发布**不会替换**它 | 长期存在，改动不会白做 | **默认可写**（仍受档位约束） |
| **乙 · 外部上游** | 随新版本**整体替换**：submodule、vendored 库、peer 依赖 | 一次升级即抹平 | **X 档绝对只读**；只经已文档化的公开面集成 |
| **丙 · 版本耦合的脚手架** | 从模板/fork 继承，且**与上游版本强耦合**：补丁、CI 配置、根 manifest | 上游一动就可能失效 | **只读**，需当轮特别授权 |

### 这条分界线给出一个可直接用于排期的推论

- **乙、丙类里的改动有「无用功」风险** —— 上游一升版就可能整体失效。
- **甲类里的改动不会。**

故：**凡咬住上游具体形状的待办**（依赖上游类名/token、依赖未文档化的面、
依赖「上游某字段恒空」这种**当前版本的性质**），要么排在 pin 更新轮之后，
要么把耦合**集中到一处 + 注释标注上游版本**，把返工面压到最小。

---

## 二、档位（A–X） 【必选】

档位描述的是**「动它的代价」**，与来源分类正交：一个甲类文件也可能是 C 档。

| 档 | 含义 | 典型内容 | 处置 |
|---|---|---|---|
| **A** | 自由 | 本体源码、测试、本机工具脚本 | 直接改 |
| **B** | 谨慎 | 包清单、构建配置、tsconfig、根 manifest | 改，但要在计划里说明为什么 |
| **C** | 先论证 | 项目规则文档、根级 README、仓库脚本、CI 配置 | **先论证再改**，论证写进当轮记录 |
| **D** | 受限资产 | 美术/二进制素材、大文件资源 | **先论证**；改动可能触发门禁 |
| **E** | 文档体系 | 治理根下的全部文档 | 可写，但受各自的容器纪律约束 |
| **F** | 隔离工作区 | 保持脚手架状态的包、实验性目录 | 硬停，只读 |
| **X** | 永不 | 上游子树、lockfile、`node_modules/`、生成物 `dist`/`lib`、运行时数据目录 | **绝不触碰** |

### 三条容易搞错的地方

1. **生成物「可写」的准确含义是「由工具链写」**。
   手工编辑生成文件仍然**是 X 档** —— 改源码再重建，绝不就地打补丁。
2. **「文档不是代码」**：文档体系是可写的。若连治理记录也冻结，就无法登记、无法立计划、无法留痕——
   体系会当场死掉。
3. **`build/**` 这类素材目录通常是 D 档**：里面可能有**刻意不能碰**的文件
   （例如「拿来做候选但绝不能被构建消费」的素材）。尽调时要问清楚，不要假定素材目录是自由的。

## 三、「特殊授权」的精确口径 【必选】

**默认可写范围之外的一切，都只在「用户当轮原话点名」时才能改。**

- **是**授权：用户当轮原话**点名了文件、目录或具体改动**。
- **不是**授权：泛泛的「继续」「go ahead」「你看着办」。
  → **泛泛的放行不延伸到只读区。** 这句话必须写进宪法，否则默认范围会在一周内膨胀掉。
- 原话必须**逐字**记进当轮记录的「拍板落档」节。
- **越界即硬停**：停下、说明「该任务为何在可写范围内做不成」、等用户原话。
  **不得为了让门禁变绿而「临时」改根配置或门禁阈值。**

### 无派发件的直接执行（旁路）

用户当轮原话点名某个具体改动时，**可以不建派发件直接执行**——但必须：

1. 逐字记下原话（进「拍板落档」）；
2. 写明「同轮直授、未走派发」；
3. **登记一条偏差**（类型＝口径/留痕）。

**留痕不缺，又不必为一次性小改动走完整状态机。**
**不得事后补造派发文件** —— 那等于**伪造流程时序**。

## 四、写进生成件的可写范围表（模板） 【必选】

```markdown
## 可写范围（YYYY-MM-DD 用户规则）

**默认可写 = N 处：**
1. `<目录>` —— <角色>。档位：`src/**` A 档 / `<manifest>` B 档 / `README*` C 档。
2. `<生成物目录>` —— 只由工具链写；手工编辑仍 X 档。
3. `<本机工具目录>` —— A 档，<N> 个文件，是文档基线之一
   （新增文件会移动基线 → 必须同轮改判据）。

**只读（除非当轮特别授权）：**
<逐个列出目录/文件 + 它们属于甲/乙/丙哪一类>

**文档不是代码**：`<GOV_ROOT>/**` 照常可写。

**「特别授权」＝用户当轮原话点名**。泛泛的「继续」不构成授权。
原话逐字记进当轮记录的「拍板落档」节。
```

配套：**待办登记模板里要有「可写范围」必填栏**，登记时就要判定
`✅ 全部触点在可写圈内` / `⛔ 有触点在圈外（逐个列出）` / `— 不涉代码`。
不要等到派发时才发现整条被挡——那浪费的是用户的时间。
