**树里的档位标记怎么读**（**权威口径；源头是 `tier-selection.md` §一**）：

| 标记 | 含义 |
|---|---|
| （无标记） | **轻量档起就有** |
| `{标准起}` | 标准 / 完整 / 重型 |
| `{完整起}` | 完整 / 重型 |
| `{重型}` | 只有重型档 |
| `{无VCS}` | **条件是「无 VCS」，与档位无关** |
| `{标准起·触发}` / `{完整起·触发}` | 档位门槛 **+** 主题物触发信号（见 `optional-containers.md`） |
| `{可选·触发}` | **无档位门槛**，只看主题物触发信号（见 `optional-containers.md`）。**轻量档也可生成** —— 用于 `缓存/` 这类「视需要」的容器 |
| `{推荐项}` | **不是档位默认** —— 走 `mandatory-vs-optional.md` §六，用户点头才生成 |

> **⚠ 这张表曾经是错的**：早期版本把 `丢弃计划/`、`执行偏差/`、`操作记录/` 画进树里
> 却**没标档位**，于是标准档被误生成出三个不该有的容器（端到端试跑实测踩到）。
> 标记语法就是为了让这类错误**可被机械检查**（`selfcheck` 的 `tree-tier-markers` 门）。
> **改树时必须同时改标记** —— 标错档位比不标更糟，因为它看起来像是有意的。

**重型档另加两个机制容器**（`<GOV_ROOT>/` 下）：

```
    ├── 发布台账.md  {重型} ← append-only：版本 / 日期 / 摘要 / 复核人 / 产物指纹
    └── 审计台账.md  {重型} ← append-only：豁免门禁 / 跳过验证 / 越过冻结面（含双签与理由）
```

> **这两份不出独立模板**（重型档是少数场景），**内容形态见
> `templates/_宪法段模板.md` **§三·补** 的「角色与权限」与「发布纪律」两节。
> 生成时按那两节的结构落到这两个文件，并**在宪法段里登记它们的路径** ——
> **载体只有一处**，不要在这两处各写一份正文（那是「规则载体多处同步」的经典翻车点）。
>
> **角色与权限矩阵**不是独立文件，它**写在宪法段的那一节里**（见同一模板）。

**微型档只生成一份 `NEXT.md`**（模板 `[_NEXT模板]`）—— 不生成上面的树。

**每个容器都要有一份 `README.md`**（用 `_容器README模板`），写清三件事：
**这里放什么 / 什么时候进 / 什么时候出**，以及**「不在这里放什么」**。
没有它，下一个会话会在三秒内做一个随机决定，然后把东西放错地方 —— 而且放错了没人发现。

**`缓存/` 的两条纪律**（写进 `工作范式.md` 与宪法段；宪法段模板里已有对应槽位）：① 一切生成物落这里，**不得写仓库根**；
② 一次性脚本放 `缓存/一次性脚本/`，`diff`/`patch`/`bak` 放 `缓存/diff/`。

**两处刻意的合并**（源实践里是独立容器，这里并掉，**并在此写明理由**）：

- **结构视图**（源实践另有 `项目结构/` 容器） → **并入 `项目清单/README.md` 的 §一**。
  理由：两者答的是同一类问题（「这个项目里有什么、哪块能写」），
  拆成两处必然出现两份互相漂移的结构描述。**一个项目只该有一处结构视图。**
- **回滚快照**（源实践另有 `归档代码/` 容器装 zip 快照） → **并入 `快照/`**。
  理由：两者的产物是同一种东西（某一时刻的全量指纹），只是打包格式不同。
  `快照/` 在有 git 时可整个删掉，`归档代码/` 不行 —— 那是源实践特有的历史包袱，不该通用化。


**生成时的三条纪律**（它们本身就是框架的示范）：

- **不发明命令**。门禁表只填尽调探到的真实命令。探不到的写 `不适用 + 原因：<原因>`，**不留空行**。
- **不覆盖既有文件**。`AGENTS.md` 已有内容 → 在末尾追加一节，并在追加处注明日期与来源理由；已有 `docs/` → 把治理根嵌进去，不要另起一棵树对抗它。
- **每个占位符都要有主**。模板里的 `<...>` 若在尽调阶段没有答案，要么问用户，要么**删掉那一节**并说明为什么不需要——不许留一个永远不会被填的空。
  **`<...>` 若本身是给生成者的指令**（例如「按档位从 `references/core/iron-rules.md` 取」），
  **生成后必须把整行删掉** —— 那些路径在目标项目里不存在，留在产物里就是死链。
  **判据**：产物里不得出现 `references/`、`templates/` 这类**只在本 skill 内成立**的路径。
