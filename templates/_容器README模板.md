# 容器 README 模板 【必选】

> **每个容器都该有一份 README。** 它回答三件事：**这里放什么 / 什么时候进 / 什么时候出**。
>
> **为什么必要**：跨会话的人**不知道这个目录是干嘛的**时，会在三秒内做一个随机决定，
> 然后把东西放错地方 —— 而且**放错了也没人会立刻发现**。
> 一份 20 行的 README 能把这个随机决定变成确定决定。
>
> **纪律**：**从不复制规则正文**。规则原文只有一处权威，README 只写**职责**与**指针**。
> 一旦 README 开始复述规则，它就会和权威慢慢分叉 —— 这就是「不留双份记录」。

---

## 模板

```markdown
# <容器名>

> <一句话：这个目录是干嘛的。>

**编辑性**：<活文档（可写） | 追加式（只增不改） | 冻结（只读，不得改写）>

## 一、这里放什么

<逐条列出允许出现的内容类型。>

## 二、怎么进

| 来源 | 条件 | 动作 |
|---|---|---|
| <从哪来> | <什么条件成立时> | <移入 / 改名 / 留下什么> |

## 三、怎么出

| 去向 | 条件 | 动作 |
|---|---|---|
| <到哪去> | <什么条件成立时> | <移动（非复制）/ 改名 / 修哪些引用> |

## 四、不在这里放什么

<**这一节最有价值。** 逐条列出容易被误放进来的东西与它真正的去处。>

- ❌ <容易误放的东西> → 应该在 `<正确位置>`，因为 <原因>

## 五、约束

- <本容器特有的纪律，例如「只追加不改写」「不得留副本」「引用只以链接形式」>

## 六、权威

<指向规则文档的哪一节。**规则原文在那里，这里不复制。**>
```

## 按容器类型填空（参考）

| 容器 | 编辑性 | 「不在这里放什么」的典型条目 |
|---|---|---|
| **活跃计划** | 活文档 | ❌ 已完成但没归档的计划（会让人以为还没做完）；❌ 休眠计划的副本或占位文件（引用只以链接 + 移交注形式） |
| **归档计划** | 冻结 | ❌ 未完成的计划（「归档」= 已闭环，误放会让后续会话找不到剩余工作）；❌ 计划中派生的未完成项（应另立新计划留在活跃） |
| **休眠计划** | 冻结（**正文冻结**） | ❌ 用户未明确暂缓的（那是活跃）；❌ 用户明确否决的（那进「丢弃」）。**休眠与丢弃的唤醒路径完全不同**。⚠ **显式例外**：状态迁移、转入依据、重启流程、双边移交注**必须可写** —— 否则唤醒流程本身就被冻结死 |
| **丢弃计划** | 冻结 | ❌ 只是「暂时没做」的（那是休眠）；**作废的号必须留号** |
| **归档文档** | 冻结 | ❌ 仍在使用中的文档；❌ 计划件（它不是计划容器，不参与完成宣告分类） |
| **问题记录** | 追加式 | ❌ 已关闭的问题（关闭后**移动**到 `问题归档/`）；❌ 「要做什么」（那是队列项，问题是「发现了什么」） |
| **执行偏差** | 活文档 | ❌ 计划内偏差的正文（权威原文在计划文档里，这里只做**抽取 + 分类 + 判定**）；❌ **多条 `DEV-NNN` 挤进一个文件**（一条一个，否则无法逐条闭环、逐条归档）；❌ 跨轮操作的偏差（那进操作记录） |
| **问题归档** | 冻结 | ❌ 未关闭的问题（那留在 `问题记录/`）；❌ 把它当成第二个问题目录 —— 它**只收已关闭的** |
| **偏差归档** | 冻结 | ❌ 未闭环的偏差（那留在 `执行偏差/`）；❌ 把它当成第二个执行偏差目录 —— 它**只收已关闭的**，与 `问题归档/` 同构 |
| **代码修改记录** | 追加式 | ❌ 叙事性的「做了什么与为什么」（那进逐轮记录；这里只放逐文件证据） |
| **操作记录** | 追加式 | ❌ 单轮实施计划内的动作；**只追加** —— 后来的变化写新的一条，不改旧的 |
| **登记提示词** | 追加式 | ❌ 工作总结（它是指令，写给下一个会话） |
| **证据** | 追加式 | ❌ 结论（这里是原始材料；结论进计划文档或走查记录） |
| **快照** | 追加式 | ❌ 覆盖已有快照（**只新增** —— 覆盖快照 = 毁掉退路） |

## 写法纪律

1. **「不在这里放什么」必须写。**
   它比「这里放什么」更有用 —— 因为出错都是因为**放错**，不是因为**放少**。
2. **20 行以内。** 超过就说明你在复述规则，该把内容搬回权威文件。
3. **冻结容器必须显式写「冻结」**，并说明**本容器**的唯一例外是什么。
   通用默认：**路径与行号的事实性更正** —— 就地更正 **+ 注记区说明**，**不静默**。
   **休眠计划是例外**：它的冻结只管正文，**状态迁移与移交注必须可写**（见上表）。
4. **给「怎么出」写清动作细节**：是**移动**还是复制？要改哪些引用？
   实测教训：计划件归档时只移动了文件、没修引用 → 引用完整性门禁变红 →
   下一轮的人花时间查一个**并不存在的问题**。
