# 执行偏差 README + 总账模板 → `docs/governance/执行偏差/` 【必选】

> 本目录是**执行期偏差的单一索引**，**不是第二份记录**。
> 每条偏差的**权威原文仍在它所属的计划文档**里；本目录只做**抽取 + 分类 + 判定**，
> **不复制正文**（`doc-sync-discipline.md` 的「不留双份记录」）。

---

## 一、`README.md` 模板

```markdown
# 执行偏差 · 总账与判定

> 立档：<日期>。本目录是**执行期偏差的单一索引**，不是第二份记录：
> 每条偏差的权威原文仍在它所属计划文档的「偏差记录」小节里，本目录只做
> **抽取 + 分类 + 判定**，**不复制正文**。逐条清单见 [偏差总账.md](偏差总账.md)。

## 一、计数口径

- **范围**：<规则文档生效日期> 起所有带「偏差记录」小节的计划文档，共 **N 份**。
- **计数单位**：该小节下的**顶层编号条目**（每份从 1 连续编到 N，无跳号、无重号）。合计 **N 条**。
- **不计入**：<范式生效前的、散写在别处的，写明为什么不并入>

## 二、双轨（**不混编**）

本目录实际记**两轨**：

| 轨 | 权威原文在哪 | 编号 |
|---|---|---|
| **计划内偏差** | 散在各计划文档的「偏差记录」节 | 每份独立编号 |
| **框架期偏差 `DEV-NNN`** | **逐条独立文件，原文即文件本身** | 全局序列 |

**两轨编号互不占用、互不换算**：不把 `DEV-005` 叫「第 229 条」，
也不把计划内第 5 条叫 `DEV-005`。
队列总表的「开放执行偏差」**只算第二轨**。

**闭环去向**：`DEV-NNN` 关闭后（补「闭环」章节 + 改本目录 `偏差总账.md` 的状态列）
**移动**（非复制）入 `../偏差归档/` —— 与 `问题记录/ → 问题归档/` 同构。
`../偏差归档/` **只读**，只收已关闭的；**未闭环的一律留在本目录**。
（判据：本目录 = 开放的，`../偏差归档/` = 已关闭的。两者不重叠、不留副本。）

## 三、六类定义与判定规则

**一条只进一类，按根因归主类**；跨类的在总账摘要里可见但不重复计数。

| 码 | 类名 | 判定规则 |
|---|---|---|
| A | 计划被证伪或改道 | **计划文本自己**的假设/落点/数值错了、漏了一态、或实施主动改写计划口径 |
| B | 实施期缺陷自纠 | 首版**实现或验证脚本自身**有 bug，被真机、门禁或收口审计抓到并修 |
| C | 外部能力缺口 | 根因在**外部能力面**：无公开面、结构性缺席、未注册、行为与文档/假设不符 |
| D | 验证与环境受限 | 根因在**本机环境/工具/沙箱**：真机不可达、验证未做、环境性门禁、平台限制 |
| E | 决策与取舍 | 根因是**产品或用户的主动取舍**：押后另立、有意边界、保留死键、采纳推荐口径 |
| F | 口径细化与留痕 | 计划只给语义/区间，实施把**数值、命名、签名、结构**钉死；以及收尾记录与「无偏差」声明 |

**两条边界规则（判定分歧最多处）**：

1. **根因在外部 → C 不归 A**。字面看是「计划假设被证伪」，但根因是外部没提供 → 归 C。
2. **只影响验证 → D 不归 C**。同一根因，后果只是取不到证、产品行为未变 → 归 D；
   若导致**功能降级** → 归 C。

> **F 类里有一部分严格说不是偏差**，是留痕与收尾记录
> （例：「无功能性偏差」「与验收口径一致，非模拟」）。

## 四、复读最多的同一条

<**这张表是这套体系最有诊断价值的一处** —— 同一个根因反复出现，
说明它不是偶发，而是**结构性的**，该被制度解决而不是逐次修。>

| 条目 | 次数 | 说明 |
|---|---|---|
| | | |

## 五、判定：哪些需要做，哪些不需要做

**结论先说**：N 条里 **M 条不需要任何动作**（当轮已闭环、口径已回写进规则或已落单测钉住）。

### 5.1 必须做
### 5.2 建议做
### 5.3 需要用户点头（不自行推进）
### 5.4 条件触发才做
### 5.5 明确不做（**含理由**）

> **「明确不做」这一节必须写理由。** 不写理由的「不做」在下一轮会被重新提出，
> 然后被重新讨论一遍。

## 六、维护纪律

1. **新轮次闭环时**：主规则文件照旧在当轮计划里写偏差记录；本目录**只在下列情况更新** ——
   新增编号条目、某条开放项被闭环或被否决、出现新的复读条目。
   **不要求每轮重写分布表与趋势**，但**条数变了必须同步**。
2. **判定改动留痕**：把「不做」翻成「做」要在该行留下**日期与依据**，**不得静默改写**。
3. **不做第二份正文**：任何情况下都不把计划文档里的偏差正文抄进本目录。
4. **跨轮操作的偏差不进本账**：那些落 `操作记录/`，**不并入**——
   否则两套口径会互相污染。
```

## 二、`偏差总账.md` 模板

```markdown
# 偏差总账

> 本表是从各计划文档的「偏差记录」节**机械抽取**的；分类码是**唯一的人工输入**。
> 若怀疑抽取有误，**以计划文档原文为准**。

## 一、计划内偏差索引

| # | 出处 | 摘要 | 分类 |
|---|---|---|---|
| 1 | <计划> §七 1 | <加粗标题> | A |

## 二、框架期 `DEV-NNN` 索引

| # | 文件 | 标题 | 分类 | 状态 |
|---|---|---|---|---|
| DEV-001 | `DEV-001-<slug>.md` | | | 开放 / 已闭环 |
```

**「总账可重生成」**：表体是机械抽取的，所以它可以被脚本重建 ——
这一条要写进维护纪律，否则有人会手动维护它，然后它悄悄漂移。
