> 它是新会话**默认阅读顺序的第三站**，一个文件里同时承担四件职责：
>
> 1. 计划索引（哪些计划开着）
> 2. 当前结论（现在处于什么状态）
> 3. **最近 N 轮状态块** —— 完成宣告第 3 步的落点

>
> 生成树里点了这个文件，但没有它，**完成宣告的第 3 步与第 5 步无处可落**。

## 三条写法纪律

1. **计数不复制。** 本文件不写「当前有 N 条开放问题」——那是总表的事。
   引用时**指向总表**。理由见 `doc-sync-discipline.md` §二。
2. **「最近 N 轮」必须是定长窗口**（通常 3 轮）。它**不是**状态日志。
   一旦开始无限追加，它就会退化成第二个逐轮记录，然后两份互相矛盾。
3. **代码地图三节的日期戳必须随轮更新**，**无变化也要显式写一行**：
   「文件作用清单无需同步（未增删/改名文件，作用无实质变化）」。
   静默跳过与漏做同罪 —— 下一轮无法区分「查过没有变化」与「根本没查」。
