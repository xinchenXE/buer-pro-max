## 一、编号序列

> **本表同时是「已登记序列」的名册。** 项目新增任何编号序列（如判据 `J-NN`），
> **必须同轮加一行** —— 未登记的序列不受任何唯一性保护，会撞号且无人发现。

| 序列 | 下一个可用 | 已用 | 真源文件 | 说明 |
|---|---|---|---|---|
| 队列项 `NNN` | 001 | 0 | 本表 §三 | 永不复用；作废不删号 |
| 问题 `ISS-NNN` | 001 | 0 | `../问题记录/` | 逐条独立，带状态机 |
| 偏差 `DEV-NNN` | 001 | 0 | `../执行偏差/` | 与「计划内偏差」两轨不混、不换算 |
| 操作 `OP-NNN` | 001 | 0 | `../操作记录/` | 完整档起；跨轮动作与删除三类动作 |
| 轮次 | R01 | 0 | `../活跃计划/项目总结.md` | 与逐轮记录的章节号一一对应 |
| <项目自生序列> | | | <真源文件> | 有判据清单 / 模块前缀等才登记 |

**真源文件列必填**：判「这个号有没有被用」只看该文件，**不要全仓 grep**
（会命中本表这类宣告行）。

**并行编号的必要性**：一个队列项可以横跨多轮；一个问题可能登记时还不成计划；
偏差分两轨（计划内 / 框架期）。**合一会让所有关系变成一对一，任何一对多都得再发明一个副号。**
