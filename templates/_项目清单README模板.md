## 三条写法纪律

1. **本文件不复制规则正文。** 它**只画结构与档位**，每条规则的权威仍在原处，
   本文件只给**指针**。理由是 `doc-sync-discipline.md` §一 的「规则载体多处同步」。
2. **§八 「待更新」必须存在**，哪怕写「无」。
   一份看起来全量、实际有暗洞的清单，比一份明说「这里还没更新」的清单**危险得多**。
3. **日期戳**。每个计数、每个档位表都带最后核对日期。
   这是 `anti-patterns.md` #17 「平台事实要写成实测一节」在文档层的同款应用。
